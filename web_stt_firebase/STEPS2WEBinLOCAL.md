• To run it yourself locally:

  1. Go to the app folder:

  cd /home/aes/cobot2_ws/web_stt_firebase

  2. Install dependencies if needed:

  npm install

  3. Start the local dev server:

  npm run dev

  4. Open the URL Vite prints, usually:

  http://localhost:5173/

  If port 5173 is busy, Vite will show another port like 5174.

  Keyboard controls:

  - 1 to 5: change wave size
  - q: none / idle
  - w: almond / red
  - e: pistachio / green
  - r: cashew / yellow
  - t: walnut / purple

  You can stop the server with Ctrl+C in the terminal.
